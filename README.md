# FDU-BTR

FDU-BTR is a global monthly surface-ocean pCO2 reconstruction workflow based on a Background–Thermal Residual framework.

## Contents

- Input data preprocessing
- Multi-product background climatology construction
- BTR target decomposition
- Basin-specific residual model training
- Boundary blending
- Monthly NetCDF generation
- Validation and uncertainty diagnostics
- Figure generation

## Dataset

The FDU-BTR pCO2 dataset is available at:
https://doi.org/10.5281/zenodo.20152530
